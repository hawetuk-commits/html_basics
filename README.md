# HTML Basics

A collection of standalone HTML and CSS practice pages, plus a small web-programming class project. The examples cover basic page structure, text and links, forms, tables, lists, semantic elements, CSS styling and layout.

## View the examples

No build step or package installation is required. Open any `.html` file in a web browser. For example, start with:

- `p1.html`, `p2.html` and `p3.html` for web-programming class pages
- `examples.html` and `ex2.html` for simple website examples
- `form.html`, `select.html` and `button.html` for form controls
- `table.html` and `table2.html` for tables
- `position.html` and `grid.html` for CSS layout practice

The `web-programming-project/` folder contains another set of class-project pages. Open its `index.html` in a browser to view its main page.

## Repository contents

- HTML files in the root: individual lessons and practice examples
- `index.css` and `script.js`: small shared CSS and JavaScript examples
- `images/`: image assets used by some pages
- `web-programming-project/`: a separate group of project pages and its stylesheet
